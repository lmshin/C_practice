# C 언어로 구현한 자료구조

이 저장소는 C 언어로 구현된 다양한 자료구조들을 모아 놓은 프로젝트입니다. 각 자료구조의 기본 개념을 이해하고 직접 구현해보며 C 언어에서의 효율적인 데이터 관리 방법을 익히는 데 중점을 두었습니다.

---

### 🚀 프로젝트 목표

* **기본 자료구조 이해:** 스택, 큐, 연결 리스트, 트리 등 핵심 자료구조의 동작 원리 학습.
* **C 언어 구현:** 포인터, 동적 메모리 할당 등 C 언어의 특징을 활용하여 자료구조를 직접 구현.
* **코드 가독성 및 효율성:** 클린 코드를 지향하며, 각 자료구조의 시간 복잡도와 공간 복잡도를 고려한 효율적인 구현.

---

### 📁 포함된 자료구조

현재 프로젝트에 포함되어 있거나 향후 추가될 자료구조는 다음과 같습니다:

* **배열 (Array)**
    * 기본 배열 연산 (삽입, 삭제, 검색)
* **연결 리스트 (Linked List)**
    * 단일 연결 리스트 (Singly Linked List)
    * 이중 연결 리스트 (Doubly Linked List)
    * 원형 연결 리스트 (Circular Linked List)
* **스택 (Stack)**
    * 배열 기반 스택
    * 연결 리스트 기반 스택
* **큐 (Queue)**
    * 배열 기반 큐
    * 연결 리스트 기반 큐
* **트리 (Tree)**
    * 이진 트리 (Binary Tree)
    * 이진 탐색 트리 (Binary Search Tree, BST)
    * AVL 트리 (AVL Tree) / 레드-블랙 트리 (Red-Black Tree) (향후 추가 예정)
* **힙 (Heap)**
    * 최소 힙 (Min-Heap) / 최대 힙 (Max-Heap) (향후 추가 예정)
* **해시 테이블 (Hash Table)**
    * 체이닝 (Chaining) / 개방 주소법 (Open Addressing) (향후 추가 예정)
* **그래프 (Graph)**
    * 인접 행렬 (Adjacency Matrix)
    * 인접 리스트 (Adjacency List)
    * 그래프 탐색 알고리즘 (BFS, DFS) (향후 추가 예정)

각 자료구조는 별도의 디렉토리에 분리되어 있으며, 해당 디렉토리 내에 구현 파일 (`.c`)과 헤더 파일 (`.h`)이 포함되어 있습니다.
